# Instructions for AI tools

Read [CONTRIBUTING.md](CONTRIBUTING.md) before adding or changing a patch, and follow it.

The rules of the [AGENTS.md file of Concrete CMS](https://github.com/concretecms/concretecms/blob/HEAD/AGENTS.md) about the text you write (pull request descriptions, comments, commit messages) apply to this repository too.

Don't change a patch that's already included in a released version without saying it explicitly: it changes the code installed by who already uses that version of the patched package.
